# キャッチバレー とくてん板（GAS版）の入れ方

記録係がタブレットで点数とラリーを数え、試合の終わりに1回だけスプレッドシートへ送るウェブアプリです。
記録は1試合1行でたまります。チームを選ぶと、そのチームの試合の一覧とラリーの折れ線グラフが出ます。
子どもの名前は扱いません。記録するのはチーム名・点数・ラリーだけです。

## 使うファイル
- `Code.gs`（サーバー側）
- `index.html`（画面）

## 入れ方（学校のアカウントで1回だけ）
1. 学校のGoogleアカウントで、新しいスプレッドシートを作ります。名前は「キャッチバレー とくてん板（記録）」などにします。
2. メニューの「拡張機能」から「Apps Script」を開きます。
3. 最初からある「コード.gs」の中身をすべて消し、`Code.gs` の中身を貼りつけて保存します。
4. 左の「ファイル」の＋から「HTML」を選び、名前を `index` にします。中身をすべて消し、`index.html` の中身を貼りつけて保存します。
5. 右上の「デプロイ」から「新しいデプロイ」を選び、種類は「ウェブアプリ」にします。
   - 次のユーザーとして実行：自分
   - アクセスできるユーザー：（学校のドメイン）内の全員
6. 「デプロイ」を押すと、アクセスの承認を求められます。自分のアカウントを選んで許可します。許可するのは、このスプレッドシートの読み書きだけです。
7. 出てきたウェブアプリのURLを、Classroomなどで子どもに配ります。

## チーム名を変えるとき
スプレッドシートの「チーム」シートのA列を書きかえます。行を足すとチームがふえます。アプリを開き直すと反映されます。

## コードを直したとき
Apps Scriptで保存したあと、「デプロイ」から「デプロイを管理」を開き、鉛筆のボタンで「新バージョン」を選んでデプロイします。URLは変わりません。

## 気をつけること
- 体育館の電波が弱くても、点数とラリーはタブレットの中で数えます。送れなかった記録はタブレットに残り、30秒ごとと電波が戻ったときに送り直します。
- 同じ記録が2回届いても、シートには1行だけ入ります。
- 画面の上に「このアプリケーションは Google Apps Script のユーザーによって作成されたものです」と出ます。自作のウェブアプリでは必ず出る表示です。
